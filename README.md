# TrashCan
Automatic Opener TrashCan

Components Needed

    ESP32-C3 Super Mini (The "brain")

    HC-SR04 Ultrasonic Sensor (To detect your hand)

    SG90 Micro Servo Motor (To lift the lid)

    Power Source (5V via USB-C or a 3.7V Li-ion battery)

    Jumper Wires and a small breadboard (or soldering iron)
